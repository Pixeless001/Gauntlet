# Dependency audit
Confirm the dependency is necessary and not already supplied by the platform or repository. Inspect locked version, license, maintenance source, install scripts, transitive growth, known advisories, runtime footprint, and replacement/removal cost. Use authoritative registry and advisory evidence and distinguish unavailable evidence from safety.
