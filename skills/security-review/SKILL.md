# Security review
Map inputs, identities, authorization decisions, secrets, persistence, and outputs. Check broken access control, injection, unsafe deserialization, credential exposure, cryptographic misuse, and fail-open behavior using repository and platform evidence. Report concrete exploit preconditions and affected boundaries; do not issue generic severity scores.
